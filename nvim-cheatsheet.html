Ta configuration

L'essentiel de ta config

  • ␣Attendre un instant : which-key affiche la suite possible
  • ␣?Tous les raccourcis, avec recherche
  • ;;En insertion : revenir en mode normal
  • ␣nhEffacer le surlignage de recherche
  • ␣yaCopier tout le fichier
  • Alt-j/Alt-kDescendre / monter la ligne ou la sélection
  • ␣atAngular : basculer entre .ts et .html
  • ←↑↓→Désactivées en mode normal : utilise h j k l

Trouver (Telescope)

  • ␣ffFichier par son nom
  • ␣fgTexte dans tout le projet
  • ␣fxMot sous le curseur dans le projet
  • ␣fbBuffers ouverts
  • Ctrl-j/Ctrl-kRésultat suivant / précédent
  • EntréeOuvrir
  • Ctrl-v/Ctrl-xOuvrir en split vertical / horizontal
  • Ctrl-qEnvoyer les résultats dans la quickfix
  • Ctrl-u/Ctrl-dFaire défiler l'aperçu
  • Ctrl-cFermer

Explorateur (nvim-tree)

  • ␣eOuvrir / fermer, positionné sur le fichier courant
  • aCréer (finir par / pour un dossier)
  • r/dRenommer / supprimer
  • x/c/pCouper / copier / coller
  • y/Y/gyCopier le nom / chemin relatif / chemin absolu
  • H/IAfficher les fichiers cachés / ignorés par git
  • Ctrl-v/Ctrl-xOuvrir en split vertical / horizontal
  • -Remonter au dossier parent
  • W/RTout replier / rafraîchir
  • fFiltrer l'arborescence
  • $Lancer une commande shell dans ce dossier
  • g?Aide de l'explorateur

Buffers et fenêtres

  • Shift-h/Shift-lBuffer précédent / suivant
  • ␣bd/:BdFermer le buffer sans fermer la fenêtre
  • Ctrl-^Revenir au buffer précédent
  • Ctrl-h/Ctrl-j/Ctrl-k/Ctrl-lAller à la fenêtre de gauche / bas / haut / droite
  • :vsp/:spDiviser verticalement / horizontalement
  • Ctrl-w=Égaliser la taille des fenêtres
  • Ctrl-woNe garder que la fenêtre courante
  • Ctrl-wqFermer la fenêtre

Code (LSP)

  • gd/gDAller à la définition / déclaration
  • gRToutes les références
  • gI/gtImplémentations / définition du type
  • KDocumentation (K une 2ᵉ fois pour entrer dedans)
  • gs/Ctrl-sSignature de la fonction (normal / insertion)
  • ␣caCode action : correction rapide, import…
  • ␣rnRenommer le symbole dans tout le projet
  • ]d/[dErreur suivante / précédente
  • ␣d/␣DDétail de l'erreur / toutes celles du fichier
  • gOSymboles du fichier
  • ␣thAfficher / masquer les inlay hints
  • ␣rsRedémarrer le LSP
  • Ctrl-o/Ctrl-iRevenir / repartir après un saut

Diagnostics (Trouble)

  • ␣xxErreurs de tout le projet
  • ␣xXErreurs du fichier
  • ␣csSymboles du fichier en panneau
  • ␣clDéfinitions et références en panneau
  • ␣xQ/␣xLQuickfix / location list

Complétion, snippets, Copilot

  • Ctrl-EspaceOuvrir le menu de complétion
  • Ctrl-j/Ctrl-kSuggestion suivante / précédente
  • EntréeValider (seulement si une suggestion est choisie)
  • Ctrl-eFermer le menu
  • Ctrl-f/Ctrl-bFaire défiler la documentation
  • Ctrl-l/Ctrl-hSnippet : champ suivant / précédent
  • TabCopilot : accepter la suggestion grisée
  • Alt-→Copilot : accepter le mot suivant
  • Alt-]/Alt-[Copilot : proposition suivante / précédente
  • Ctrl-]Copilot : ignorer

Parenthèses, guillemets et balises HTML se ferment tout seuls.

Formatage et sauvegarde

  • ␣mpFormater le fichier ou la sélection
  • :ConformInfoVoir quel formateur s'applique

Le fichier est formaté à chaque sauvegarde, et sauvegardé quand tu quittes le buffer ou que Neovim perd le focus.

Git (gitsigns)

  • ]h/[hModification suivante / précédente
  • ␣hpVoir la modification
  • ␣hsIndexer le hunk (encore une fois pour le retirer)
  • ␣hrAnnuler le hunk
  • ␣hS/␣hRIndexer / annuler tout le fichier
  • ␣hb/␣hBBlame de la ligne / blame permanent
  • ␣hd/␣hDDiff avec l'index / le commit précédent
  • ihObjet « hunk » : v i h, d i h

Recettes

  • ␣fg…Ctrl-q1. Chercher le texte, envoyer en quickfix
  • :cdo s/a/b/g | update2. Remplacer a par b partout et sauvegarder
  • ]d…␣caAller à l'erreur suivante et la corriger
  • :LspEslintFixAllAppliquer toutes les corrections ESLint
  • :TodoTelescopeLister les TODO, FIXME, HACK du projet

Remplacer dans tout le projet se fait en deux temps : les deux premières lignes.

Vim, les bases

Se déplacer

  • hjklGauche, bas, haut, droite
  • wbeMot suivant / précédent / fin du mot
  • WBEPareil, en ignorant la ponctuation
  • 0/^/$Début de ligne / premier caractère / fin
  • gg/GDébut / fin du fichier
  • :42Aller à la ligne 42
  • f{c}/t{c}Jusque sur / avant le caractère c (F, T vers la gauche)
  • ;/,Répéter le f/t dans un sens / dans l'autre
  • %Parenthèse ou accolade correspondante
  • {/}Paragraphe précédent / suivant
  • Ctrl-d/Ctrl-uDescendre / monter d'une demi-page
  • zz/MCentrer l'écran sur le curseur / curseur au milieu
  • */#Occurrence suivante / précédente du mot

H et L ne vont plus en haut / bas de l'écran : ils changent de buffer.

Éditer

  • i/aInsérer avant / après le curseur
  • I/AInsérer en début / fin de ligne
  • o/ONouvelle ligne en dessous / au-dessus
  • d/c/ySupprimer / changer / copier + mouvement (d w, c $, y 3j)
  • dd/cc/yyPareil sur la ligne entière
  • D/CSupprimer / changer jusqu'à la fin de la ligne
  • x/r{c}Supprimer / remplacer le caractère
  • p/PColler après / avant
  • u/Ctrl-rAnnuler / refaire
  • .Répéter la dernière modification
  • >>/<<Indenter / désindenter
  • gg=GRéindenter tout le fichier
  • JJoindre la ligne suivante
  • gcc/gcCommenter la ligne / commenter + mouvement
  • gU/gu/~Majuscules / minuscules + mouvement / inverser la casse

Objets texte

  • iw/awMot (a w inclut l'espace)
  • i"/a"Contenu d'une chaîne / chaîne entière
  • i(/i{/i[Contenu des parenthèses / accolades / crochets
  • it/atContenu d'une balise HTML / balise entière
  • ip/apParagraphe

À combiner avec un opérateur : c i " réécrit une chaîne, d a t supprime une balise, y i { copie un bloc.

Mode visuel

  • v/V/Ctrl-vCaractères / lignes / bloc
  • gvResélectionner la dernière sélection
  • oAller à l'autre bout de la sélection
  • Ctrl-v…ItexteÉchapInsérer le même texte sur plusieurs lignes
  • Ctrl-v…$AtexteÉchapAjouter en fin de plusieurs lignes
  • >/<Indenter / désindenter la sélection

Rechercher et remplacer

  • /texte/?texteChercher vers le bas / le haut
  • n/NRésultat suivant / précédent
  • :%s/a/b/gRemplacer a par b dans le fichier
  • :%s/a/b/gcPareil, en confirmant chaque remplacement
  • :s/a/b/gDepuis une sélection : remplacer dedans

La recherche ignore la casse, sauf si tu tapes une majuscule.

Presse-papiers et registres

  • y/pUtilisent directement le presse-papiers Windows
  • "_dSupprimer sans écraser le presse-papiers
  • "0pColler le dernier texte copié (pas supprimé)
  • "ay/"apCopier dans / coller depuis le registre a
  • Ctrl-r{reg}En insertion : coller un registre
  • :regVoir le contenu des registres

Macros et marques

  • qa…qEnregistrer une macro dans a
  • @a/@@Rejouer la macro a / la dernière
  • 10@aRejouer 10 fois
  • ma/'aPoser la marque a / y revenir
  • `.Revenir à la dernière modification
  • giReprendre l'insertion là où tu l'as quittée

Fichiers et terminal

  • :w/:waSauvegarder / tout sauvegarder
  • :q/:qa/:q!Quitter / tout quitter / sans sauvegarder
  • :e cheminOuvrir un fichier
  • :term cargo runLancer une commande dans un terminal intégré
  • Ctrl-\Ctrl-nSortir du mode terminal
  • :!commandeLancer une commande shell ponctuelle

Aucun raccourci ne correspond. Échap pour effacer le filtre.
